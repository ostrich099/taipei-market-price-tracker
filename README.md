# 台北市場價格追蹤器

## 專案動機
台灣近年物價持續上漲，日常買菜的花費也越來越有感。這個專案希望能有一個參考依據，讓自己在買菜前能先掌握主要蔬菜的價格趨勢，未來目標是對照住家附近台北市太平市場的實際零售價格。

## 資料來源
農業部「農產品交易行情」開放資料 API（https://data.moa.gov.tw），追蹤台北一批發市場的批發價格。目前追蹤15種常見蔬菜，包含高麗菜、青江菜、番茄、小黃瓜等。

**注意**：此資料為批發價，非市場零售價，用途為觀察價格趨勢，非直接對應零售市場實際售價。

## 技術架構
- **Python** + `requests`：串接政府開放資料API
- **SQLite**：儲存歷史價格資料，並以唯一鍵（品項、日期、市場、作物名稱）避免重複寫入
- **pandas**：讀取品項對照表、資料整理

## 遇到的挑戰與解法
1. **品項名稱不一致**：日常口語（如「高麗菜」「小黃瓜」）與農業部系統的正式名稱（「甘藍」「花胡瓜」）不同，且同一品項常細分多個品種代碼。透過人工比對北農品項代碼表，建立品項對照表（`vegetables.csv`）解決。
2. **API連線不穩定**：政府開放資料API偶有連線逾時的狀況，加入 `try/except` 錯誤處理，確保單一品項失敗不會導致整個抓取流程中斷。
3. **資料累積問題**：初版設計會覆蓋既有資料，無法用於排程自動化。改用SQLite搭配唯一鍵約束，實現「新增不重複」的累積式儲存。
