# 🥬 食價寶寶｜台北市場價格追蹤器

以農業部開放資料打造的雙北蔬菜價格追蹤系統，提供**台北一、台北二與雙北綜合價格**的每日趨勢，協助使用者在前往市場買菜前，快速判斷當前價格是否偏高或正常。

🔗 線上體驗：https://shijiabaobao.streamlit.app

## 專案背景

這個專案源於一個很生活化的問題。

住家附近的太平市場沒有公開零售價格資料，因此我重新定義 MVP，改以**台北批發市場價格作為趨勢參考指標**，而非直接比對零售價，並透過每日自動更新建立可持續累積的歷史價格資料。

本專案主要作為**產品企劃、需求分析與系統實作**的練習，完整驗證從需求定義、資料規格、資料處理到網頁展示的流程。

## 我在專案中負責的內容

- **需求定義**：重新界定 MVP，評估資料來源可行性與產品定位
- **資料規格制定**：建立 15 項常用蔬菜的口語名稱與官方品項對照表（`vegetables.csv`）
- **資料整合設計**：規劃台北一、台北二市場資料整合，並以交易量加權計算雙北綜合價格
- **資料庫與自動化**：設計 SQLite 累積式儲存架構，搭配 GitHub Actions 每日自動更新
- **資料驗證與問題排查**：驗證 API、處理版本衝突、部署雲端並完成 Streamlit 視覺化介面

本專案使用 AI 作為技術協作工具，我負責需求判斷、資料驗證、規格制定、測試與決策，完成整體產品落地。

## 系統功能

- 雙市場切換（台北一／台北二／雙北綜合）
- 公斤／台斤單位切換
- 特定日期價格查詢
- 歷史價格趨勢圖
- 每日價格明細表
- GitHub Actions 每日自動更新資料

## 技術架構

| 技術 | 用途 |
|---|---|
| Python + Requests | 串接農業部開放資料 API |
| Pandas | 資料清理、彙整與加權平均 |
| SQLite | 累積歷史價格與去重複儲存 |
| GitHub Actions | 每日自動排程更新 |
| Streamlit | 網頁介面與資料查詢 |
| Plotly | 趨勢圖視覺化 |
| Figma | Wireframe 介面設計 |
